# SET SMART AI Trader

ระบบวิเคราะห์หุ้นอัตโนมัติด้วย Python สำหรับสมาชิก SET SMART

## 📌 ความสามารถ
- ดึงข้อมูลหุ้นจาก SET SMART API
- วิเคราะห์หุ้นเล่นสั้น (Volume, NVDR, Big Lot)
- วิเคราะห์หุ้นเล่นยาว (ปันผล, DCA, พื้นฐาน)
- ทดสอบกลยุทธ์ย้อนหลัง (Backtest)
- แจ้งเตือนผ่าน LINE

## 🔑 ก่อนเริ่มใช้งาน (สำคัญ)
โปรเจกต์นี้ **ไม่มี API Key ให้** คุณต้องเป็นสมาชิก SET SMART และขอ Key เอง

1. สมัครสมาชิก SET SMART (เสียค่าสมาชิกเอง)
2. ขอ API Key จาก SET SMART
3. ใช้ Key ของตัวเองเท่านั้น
